YUVANESH SHARMA S — PORTFOLIO

FILES
- index.html: Home page
- projects.html: Projects, skills, and contact page
- style.css: Shared responsive styling and themes
- script.js: Menu, theme, project filters, form validation

RUN LOCALLY
1. Open this folder in VS Code.
2. Open index.html in a browser, or use the VS Code Live Server extension.
3. Keep all four files in the same folder.

BEFORE PUBLISHING
- Replace placeholder GitHub links (https://github.com/) with your profile/project URLs.
- Replace sample project cards with your real projects.
- Update the skills to reflect your actual experience.
- The contact form is demo-only: it validates input but does not send messages.
- Deploy the folder to Netlify when you're ready.
